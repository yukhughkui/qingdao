# 轻岛 · 把每一步，种成风景

运动与习惯记录 × 体重趋势 × 小岛养成。

轻岛是一个面向成年人的轻量网页工具：记录日常活动、积累能量、解锁岛上风景，让习惯养成多一点趣味，少一点压力。体重只是可选记录，不作为奖励或评价依据。

**当前仓库是网站版，不是微信原生小程序。** 使用 HTML、CSS 和 JavaScript，无需安装前端依赖、无需构建，也无需自建后端，可以部署到 GitHub Pages。

## 功能概览

| 模块 | 功能 |
| --- | --- |
| 今日 | 每日活动目标、完成进度、能量、连续活动天数、三项习惯打卡 |
| 运动时光 | 步行、舒展、律动、恢复四类活动；训练倒计时、暂停与继续、提前结束；手工补记已完成活动 |
| 我的小岛 | 六种装饰解锁、实时变化的岛屿景观、等级与成长进度、成就系统 |
| 趋势记录 | 每周活动时长、体重趋势、同日体重更新、单条记录删除 |
| 我的 | 昵称与活动目标设置、JSON 数据导出、撤回体重记录同意、双重确认重置 |

手工补记属于用户自报记录，不是自动检测运动。本版没有账号登录、公开社区、排行榜、支付或付费虚拟币。

## 第一次使用

1. 打开已部署的网站。首屏为明确标识的**虚构示例数据**，仅用于体验功能，不代表实际运动或减重效果。
2. 点击「切换我的数据」或「开始我的记录」，进入独立的个人存档。
3. 在运动页记录已经完成的活动，或使用训练计时功能。
4. 前往小岛，用获得的能量解锁装饰；也可以完成日常习惯打卡。
5. 体重记录为可选功能，说明用途并取得同意后才会保存。拒绝不影响运动与游戏。

体验示例：记录 15 分钟活动 → 获得 30 点能量（当天未达到能量上限时）→ 解锁小树。

**目前每次重新打开网页，默认先显示示例模式。** 需要再次点击「切换我的数据」查看之前的个人记录；这不代表存档被清空。示例存档与个人存档彼此独立。

## 仓库文件

请将下面的文件放在仓库根目录，保持名称和大小写一致：

```text
仓库根目录/
├── index.html     网页入口
├── styles.css     视觉样式与响应式布局
├── app.js         页面交互、图表与本地存储接入
├── core.js        活动、体重、能量、装饰与成就规则
├── timer.js       训练计时状态机
└── README.md      项目说明（本文件）
```

网站运行需要前五个文件。`README.md` 是说明文档，上传到仓库根目录后可在 GitHub 仓库页面查看，不改变网站功能。

当前独立发布版的脚本引用已经调整为同目录路径：

```html
<script src="core.js"></script>
<script src="timer.js"></script>
<script src="app.js"></script>
```

样式引用为 `styles.css`。不要只上传 HTML，也不要只上传 ZIP；需要上传解压后的实际文件。

本说明不依赖截图、`preview/` 或 `miniprogram/` 目录，不需要额外上传原交付说明 HTML、测试脚本、原生小程序文件或项目内部资料。

## 发布到 GitHub Pages

1. 将上述文件提交到仓库根目录。使用 GitHub Free 时，可创建公开仓库；其他账号方案的支持范围以 GitHub 官方说明为准。
2. 进入仓库的 **Settings → Pages**。
3. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
4. 选择存放文件的分支，例如 `main`；目录选择 **`/ (root)`**，点击 **Save**。
5. 等待部署完成，使用 Pages 页面显示的站点地址访问和分享。

普通项目仓库的地址通常采用下面的形式。这里是格式示例，不是已部署的实际链接：

```text
https://你的用户名.github.io/仓库名/
```

`index.html` 是网站默认首页；`README.md` 用于仓库说明，不能替代首页。GitHub 仓库内点击 HTML 文件通常显示源码，体验网站应打开 Pages 站点地址。

如果使用账号主页仓库或自定义域名，网址形式可能不同，以 Pages 页面显示的实际地址为准。

部署排查：

- **页面 404**：确认 Pages 发布分支与目录正确，且该目录内存在 `index.html`；查看仓库 Actions 的部署状态。
- **页面有外观但按钮无反应**：确认 `core.js`、`timer.js`、`app.js` 同目录上传，并保留上述加载顺序。
- **样式缺失**：确认 `styles.css` 的文件名和引用大小写一致。
- **修改后仍显示旧内容**：确认新提交已部署，再刷新；不要为了刷新页面而清除个人存档。

官方说明：[配置 GitHub Pages 发布源](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 数据保存与隐私

### 数据保存在哪里？

网页通过浏览器 `localStorage` 保存记录，格式为 JSON。个人存档键为 `light-island-v1`，示例存档键为 `light-island-browser-demo-v1`。

完成打卡、保存活动、解锁装饰、保存体重或修改设置等操作后，相应记录会写入当前浏览器。正常情况下，同一设备、同一浏览器配置、同一站点再次访问，可以读取之前的记录。

| 场景 | 当前行为 |
| --- | --- |
| 刷新页面或关闭后重新打开 | 正常情况下记录保留；切换到个人模式查看 |
| 把网站链接转发给别人 | 不会把自己的个人存档一起转发 |
| 不同设备或不同浏览器访问 | 各自保存，不自动同步 |
| 共用同一设备和同一浏览器配置 | 共用该存储环境里的个人存档，不按昵称隔离 |
| 清除站点数据或确认重置 | 相应存档被删除 |
| 无痕／隐私浏览 | 关闭全部隐私窗口后，本地记录通常会被清除 |
| 更换域名、HTTP/HTTPS 或端口 | 浏览器可能使用不同存储区域，旧存档不会自动迁移 |

浏览器存储按站点来源（协议、域名、端口）隔离，**不是按 GitHub 仓库目录隔离**。同一域名下重复部署使用相同存档键的本项目，可能共享同一份浏览器记录。

当前应用没有上传个人活动或体重记录的后端，也没有供运营者查看用户记录的后台。GitHub Pages 提供网页托管，不是本项目的个人记录数据库；托管服务自身的访问日志以其隐私政策为准。

### 保存的限制

- 本地记录没有额外加密，共用设备可能被他人看到。
- 浏览器清理、无痕模式、存储禁用、容量限制等可能导致记录无法保留，不承诺永久保存。
- 存储失败时会显示错误，不把未保存的数据误报为成功，也不自动清空旧存档。
- 关闭网页不会自动保存并恢复未结束的训练计时状态。
- 可在「我的」中导出 JSON 备份；当前没有图形化导入恢复入口。导出文件可能包含体重等个人信息，请妥善保管，不要上传到公开仓库。
- 体重记录可以单条删除；撤回同意会清空体重记录；全部记录重置需要两次确认。

## 电脑与手机适配

同一个网址、同一套网页代码，根据浏览器视口宽度自动调整布局，不需要另外上传手机版。

- `index.html` 配置 `width=device-width, initial-scale=1` 视口参数。
- CSS 使用 Grid、Flex、弹性宽度和媒体查询。
- 在 1180px、950px、640px 等宽度处调整布局；宽度不超过 640px 时隐藏左侧栏，启用底部导航，活动列表与表单改为单列，商店改为两列。
- 手机底部导航考虑安全区留白，弹窗限制宽度并允许内部滚动。

已有截图来自浏览器视口：桌面 **1365 × 1000**、手机 **390 × 844**。它们不是微信真机截图，也不代表所有手机和浏览器都已验证。

## 主要规则

| 规则 | 当前实现 |
| --- | --- |
| 运动能量 | 每记录一分钟活动获得 2 点能量，每天最多 80 点运动能量 |
| 活动记录 | 每笔 1–120 整数分钟，每日累计最多 180 分钟 |
| 日常习惯 | 喝水、离开座位、留休息时间，各奖励 5 点，每个自然日最多一次 |
| 等级 | 每累计 100 点经验提升一级 |
| 装饰 | 每件仅解锁一次；购买扣能量，不扣经验和等级 |
| 体重 | 可选、明确同意后保存；每日一条，同日更新，保留一位小数，不奖励减重 |
| 输入校验 | 体重 20–350 kg 仅用于拦截异常输入，不代表健康范围或建议目标 |
| 训练计时 | 页面切到后台时暂停；提前结束只结算实际整分钟，不足一分钟不记活动 |
| 历史保留 | 最多 365 天日记录、365 条体重和 100 条近期活动；累计时长与经验独立保留 |

这些上限是产品记录与奖励规则，**不是医学建议**。不规定固定喝水量，也不鼓励为了积分过量运动。
