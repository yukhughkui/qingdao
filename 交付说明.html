LIGHT ISLAND / DELIVERY v1.0.0

轻岛：把每一步，种成风景。

运动记录 × 体重趋势 × 休闲养成，本地优先的微信原生小程序。

当前交付的是可运行源码与浏览器交互演示，不是已发布的小程序。
无真实小程序账号、无云环境，未进行微信开发者工具编译或真机验收。浏览器的示例数据明确标识且与个人记录隔离；微信端从空白记录开始。

一、已经做好的功能

运动与训练

步行、舒展、律动和恢复四类活动；开始、暂停、继续、结束的训练计时；手工填写已完成活动；最近活动与每周时长统计。

体重与趋势

明确同意后保存本地体重，同日更新；日期与 kg 量纲；浏览器趋势线、微信端圆点趋势图；单条删除、撤回同意和清空。

小岛养成

活动与三个习惯获取能量；六件装饰购买后实际出现在小岛上；等级、成长进度和六枚成就。纯本地玩法，无排行榜、抽奖或付费虚拟币。

个人与数据

昵称、每日自定活动目标；本机持久化；导出 JSON；双重确认重置；存储异常保留原状态，不把保存失败显示成成功。

二、怎样先看效果

  1. 打开 浏览器交互演示，可以直接切换五个模块。
  2. 首屏为明确标识的虚构示例数据。点击「切换我的数据」开始空白个人记录。
  3. 体验闭环：记录 15 分钟活动 → 获取 30 能量 → 前往小岛解锁小树。
  4. 浏览器和微信的本地存储相互独立，不会自动同步。浏览器展示不是微信模拟器。

若浏览器直接打开文件时限制本地存储，请用仅绑定本机的静态服务打开。当前机器可使用：

"C:\Users\28215\.workbuddy\binaries\python\versions\3.13.12\python.exe" -m http.server 8765 --bind 127.0.0.1 --directory "D:\微信公众号\微信小程序\qingdao"

浏览器访问：http://127.0.0.1:8765/preview/index.html

三、导入微信开发者工具

  1. 解压源码包，找到包含 project.config.json 的 qingdao 根目录。不要仅导入 preview，也不要把浏览器 HTML 当成小程序代码。
  2. 在微信开发者工具中选择「导入项目」，项目目录选 qingdao。原生源码根目录已配置为 miniprogram/。
  3. 尚无账号时，使用工具实际提供的「无 AppID / 测试号」入口。项目中的游客配置仅供本地开发，不保证具备所有真机调试和发布能力。
  4. 已注册后，由你在工具中配置正式账号，选择可用的稳定基础库并编译。配置没有固定某个未经验证的基础库数字，不需要 npm 构建、不需要云函数、不需要服务器。
  5. 先查看首页、活动、小岛、记录、我的五个 tab，再从活动页进入训练计时页面。
  6. 若编译报错，请保留报错原文和截图；不要直接删除本地记录。

规则实现
运动能量实际计时整分钟或用户自报分钟，每分钟 2 点，每天最多 80 点；每笔记录 1–120 分钟，每日总记录最多 180 分钟。上限是产品防刷规则，不是医学运动建议。
日常习惯喝水、离开座位、留休息时间，各 5 点，每个自然日最多一次；不规定固定喝水量。
小岛成长每累计 100 经验提升一级。购买装饰只扣能量，不降低经验与等级。每件装饰仅解锁一次。
体重记录可选、先同意、每日一条，保留一位小数。20–350 kg 只是输入校验范围。体重变化不影响奖励，不设置减重排行。
计时生命周期切到后台暂停，不计算后台时长。提前结束只保存实际整分钟，未满一分钟不记录。页面销毁不会自动结算；同一会话防重复保存。
历史与备份最多保留 365 天日记录与 365 条体重、100 条近期活动。导出用于保留资料，首版未提供图形化导入恢复入口。累计时长与经验独立保留。

五、验证范围与真实边界

  • 业务规则与计时：37 项自动化测试通过。
  • 原生页面：38 项模拟运行测试通过。使用 wx / App / Page mock，不等同于微信编译与真机验证。
  • JS 与 JSON 语法、所有页面四件套、注册路由、组件引用、WXML 事件及表达式已做静态检查。源码主包约 87 KiB，不含浏览器演示与测试；最终微信编译包体积仍应以工具显示为准。
  • 浏览器实际交互回归：25 项通过，涵盖五个模块、能量解锁、体重同意与删除、计时及双重重置。390px 手机尺寸没有横向溢出；结果见 tests/browser-result.txt。合计 100 项业务 / 模拟 / 浏览器测试通过。截图为浏览器演示，不是微信真机截图。

基础测试无需第三方 npm 包：

node tests/core.test.js
node tests/native.test.js
node tests/structure.test.js

浏览器回归需要安装 agent-browser、准备浏览器，并启动上述本机服务；通过环境变量 AGENT_BROWSER_CLI 指定其 CLI 文件后运行 tests/browser.test.js。此依赖只用于开发测试，不进入小程序包。

面向成年人，仅用于日常记录和休闲养成。不提供诊断、治疗、极速减重、热量处方或减重效果承诺。若身体不适或有特殊健康情况，请咨询专业人士。
